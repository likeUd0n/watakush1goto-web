# わたくしごと コンセプト

- 価値(1文):精神科・心療内科に通う人が、毎日の短い記録と話すことメモを、診察・カウンセリングで見せる1画面にまとめて、短い時間でも言い忘れずに伝えられる
  - AIを使う人だけの上乗せ:記録とメモから「何を誰に相談すればいいか」を、手持ちのAIアプリで整理できる
- 誰が:精神科・心療内科に月1〜2回通院している人（カウンセリング併用・単独利用も含む）。診察は5〜10分ほどで、言いたいことを言い忘れる、または何を言えばいいか分からない。APIキーなどの専門知識は前提にしない
- いつ・どこで:記録できる日に睡眠・調子を記録する。話したいことは思いついたときに書く。診察・カウンセリングの前日〜待合室で「準備」を見直し、診察室・カウンセリング室で「見せる」画面を相手に見せて話す。終わったら話したこととアドバイスを残す
- 使う前と後:「最近どうですか」と聞かれて「まあまあです」と答えて終わる → 前回からの記録の推移（カウンセリングでは出来事・気持ち）と、今回話すことの一覧を見せながら話せる
- 主な機能:
  - 記録（睡眠［夜・二度寝/昼寝］、調子［ココロ・カラダの5段階＋ひとこと、1日複数件］、日付切替、予定日の診察・カウンセリング記録バナー） — 相手に見せる推移になり、AIに渡す材料になる
  - これまで（月単位の推移グラフと週ごとの折りたたみ一覧・生の記録一覧切替） — 個人で長期的に振り返る場
  - 診察タブ「準備」（話すことメモ・AIの整理・前回のアドバイス・これまでの診察/カウンセリング履歴、右上カレンダーから次の予定管理） — 話す内容を整え、終わったあとに記録する場
  - 診察タブ「見せる」（診察向け：前回からの推移グラフと今回話すこと／カウンセリング向け：最近の出来事・気持ちと前回の振り返り） — 医師・カウンセラーに見せる画面
  - AIで整理する（ボタンで、前回からの記録とメモ・前回アドバイスを指示文つきで、ChatGPT・Claude・Geminiなど手持ちのAIアプリに渡す。答えを貼ると診察/カウンセリング向けに自動で振り分け・保存される） — 「何を相談すればいいか分からない」を解決する
  - 設定（診察・カウンセリングそれぞれのオン/オフ、記録のお知らせ［初期オフ・未記録の日だけ］、睡眠時刻の自動推定権限、JSONバックアップの書き出し・読み込み）
- やらないこと:
  - AIとのチャット（受け止め・セルフケア提案）、CBTのワーク、ルーティン・習慣の管理、ホーム画面
  - 服薬の記録（薬の話は話すことメモやひとことで足りる。最初の公開は小さくする）
  - 圧をかける通知・催促（記録のお知らせは初期オフで、自分でオンにした人だけ未記録の日に1回届く）
  - アプリ独自の画面ロック（端末のロックに任せる）
  - 診断・断定、サーバーへのデータ保存、PDFなどの書き出し
  - アプリの中でAIを呼ぶこと（APIキー・ローカルLLM同梱ともに最初の公開では作らない）
- 初めて見る人への説明:調子と睡眠を記録して、診察やカウンセリングのときに先生に見せる1画面にまとめます。話したいことも書きためておけます。初期状態では通知はなく、書ける日だけで大丈夫です（必要なら設定から未記録の日だけ知らせることもできます）。AIアプリを持っていれば、記録から相談したいことを整理することもできます（AIを使うときだけ、渡した先のAIの会社に送られます）。それ以外のデータはスマホの中だけに保存されます。
